How this works

This tool uses zero-shot text classification: an open-source natural-language inference model (DeBERTa-v3-xsmall, fine-tuned on MNLI) checks how well your incident description entails each candidate breach type and regulation, without ever being trained on breach examples specifically. It runs client-side via Transformers.js, so the model downloads once (cached by your browser) and every classification afterward happens instantly, offline, and privately on your own device.

Educational demo only — not legal advice. Classification quality reflects a small open-source model and a fixed label set, not a trained breach-notification system.
